## Brand & Style
The design system positions high-performance cognitive esports and reflex training as an elevated, competitive pursuit. Built on a foundation of high-contrast cyber-athletic minimalism, the interface merges the spatial polish of premium dark interfaces with intense, localized kinetic energy. It avoids muddy gaming tropes, instead favoring surgical precision: crisp dark spatial planes, deep-space contrast ratios, razor-sharp typography, and hyper-reactive chromatic energy channels.

The target audience spans competitive gamers, reaction-speed athletes, and high-focus tacticians seeking mental acuity metrics. The experience evokes lightning responsiveness, electric flow state, and decisive focus. Visual accents serve as functional state indicators—each game discipline maintains its distinct chromatic signature, erupting in controlled luminescence against an obsidian canvas.

## Colors
The palette operates with an ultra-deep charcoal black baseline that allows intense game-specific neon spectrums to read clearly without ambient visual fatigue. 

### Core Neutrals & Surfaces
- **Canvas / App Background**: `#0B0D12` (Deep Obsidian Void)
- **Surface Elevation 1 (Cards, Modals)**: `#141821` (Dense Abyssal Navy)
- **Surface Border / Separation**: `#1F2430` (Steel Slate 1px stroke)
- **Primary Text & High Emphases**: `#FFFFFF` (Pure Ice White)
- **Muted / Subtitle / Meta Text**: `#8E9BB5` (Atmospheric Blue-Gray)
- **Surface Hover Fill**: `#1A1F2C`

### Discipline & Game Accents
Each discipline has a designated kinetic accent used for category badging, high-frequency timers, targeted box-shadow glows, and dynamic state feedback:
- **Sequence Recall**: Violet `#8B5CF6` (Primary core identity, lightning energy)
- **Grid Genius**: Cyan `#06B6D4` (High-bandwidth analytical track)
- **Color Snap**: Lime `#84CC16` (Raw reflex acceleration)
- **Color Clash**: Rose `#FB7185` (Conflict resolution & dynamic inhibition)
- **Quick Tap**: Amber `#FBBF24` (Burst reaction speed)
- **Focus Frenzy**: Radiant Violet `#A78BFA` (Sustained cognitive endurance)

### Light Mode Adaptations
When toggled into light mode, the system flips to surgical high-clarity daylight:
- **Canvas Background**: `#F8FAFC`
- **Surface Cards**: `#FFFFFF`
- **Card Borders**: `#E2E8F0`
- **Primary Text**: `#0F172A`
- **Muted Meta Text**: `#64748B`
- **Accents**: Same game hues with shifted saturation and darkened text pairings for WCAG AAA compliance.

## Typography
Typography is treated as a high-precision performance instrument. The system uses a strict tripartite hierarchy:

1. **Bricolage Grotesque (Headlines & Title Planes)**: Provides athletic presence, sharp angles, and distinctive personality. Used exclusively for brand banners, arena titles, module headers, and level-up congratulations.
2. **Plus Jakarta Sans (Body Copy, Meta & Actions)**: Delivers clear, readable, and non-distracting functional copy across light and dark backgrounds. Provides balanced readability for instructional text, player profiles, and button copy.
3. **JetBrains Mono (Stats, Timers, Telemetry & Code Readouts)**: Eliminates horizontal jitter during fast numerical updates. All milliseconds, ranks, accuracy ratios, inputs-per-second, and leaderboards use JetBrains Mono tabular figures to preserve structural alignment.

## Layout & Spacing
The layout follows a 12-column responsive fluid grid anchored by strict content bounding boxes:
- **Max Content Width**: 1440px centered viewport canvas.
- **Desktop (1024px+)**: 12 columns, 24px (`1.5rem`) gutters, 32px (`2rem`) screen margins.
- **Tablet (768px – 1023px)**: 8 columns, 16px (`1rem`) gutters, 24px (`1.5rem`) margins. Game cards scale to 2-column or 4-column blocks.
- **Mobile (< 768px)**: 4 columns, 16px gutters, 16px (`1rem`) margins. Navigation tucks into a fixed floating kinetic bottom bar.

Vertical rhythm is governed by a 4px/8px modular base. Large analytical metric blocks and game card hubs maintain generous internal padding (`space-lg`) to balance the deep-toned background with breathable interactive regions.

## Elevation & Depth
Depth is created through structured tonal layering and colored kinetic glows, avoiding muddy blurs.

### Surface Hierarchy
- **Base Level 0**: `#0B0D12` solid background.
- **Level 1 (Cards, Modules, Panels)**: `#141821` background framed with a crisp, low-opacity 1px solid stroke of `#1F2430`.
- **Level 2 (Active Focus / Floating Modals)**: `#1A1F2C` elevated container with 1px `#2D3546` outline.

### Luminescence & Glow Architecture
Elevation on hover or during active play runs on a dual-stage glow engine:
1. **Per-Game Perimeter Stroke**: The 1px border transitions from `#1F2430` to the game's designated accent (e.g., `#84CC16` for Color Snap).
2. **Radial Halos**: A soft external blur (`0 0 24px -4px [accent_hex_25%]`) combined with an internal edge drop (`inset 0 1px 1px 0 [accent_hex_20%]`). This imparts a tangible, laser-etched physical glass tube feel without washing out the text contrast inside the container.

## Shapes
The design system adopts a balanced structural geometry (`roundedness: 2`):
- **Dashboard & Game Cards**: Defined with `1rem` (16px) corner radii. This softens the heavy contrast of the borders while preserving architectural density.
- **Badges, Tags & Interactive CTA Buttons**: Expressed as full circular/pill forms (`rounded-full` / `9999px`) to create an ergonomic, tactile contrast against rectangular metric cards.
- **ReflexRush Brand Emblem**: A distinct rounded-square container (16px radius) holding a purple lightning bolt glyph (`#8B5CF6`), reinforced with an inset rim shadow.
- **Stat Readout Counters**: Kept inside soft 8px (`rounded-md`) recessed cells.

## Components

### Buttons
- **Tactile Pill Buttons ("Play →")**: Primary action buttons feature an elongated stadium pill shape (`padding: 12px 28px`, `border-radius: 9999px`). Filled with primary violet `#8B5CF6` or contextual game accent color, text in contrasting bold `#FFFFFF` or `#0B0D12` (for high-luminosity accents like Lime/Amber). Features an active physical depression effect (`transform: translateY(1px)` with reduced outer shadow) to signal responsiveness.
- **Secondary Ghost Pill**: 1px `#1F2430` border with `#141821` translucent background, transitioning to bright white border with accent-tinted text on hover.

### Game Cards
- **Base State**: 16px rounded corners, `#141821` background, 1px `#1F2430` border, `space-lg` (24px) internal padding.
- **Hover State**: 1px border shifts to the distinct game accent color (e.g., `#06B6D4` for Grid Genius), coupled with a 20px diffused aura in the matching hex code at 25% opacity. The internal card art undergoes a subtle scale transform (`scale-105`) while meta copy remains crisp and fixed.

### Badge Pills & Chips
- Fully rounded stadium indicators (`height: 24px`, `padding: 0 12px`).
- Colored using an 88% alpha tint background (`[accent_hex]18`) and solid accent text, paired with `mono-label` typography for game category tags, personal bests, and real-time multiplier indicators.

### Metric Panels & Leaderboards
- Lists are divided by subtle 1px border lines (`#1F2430`).
- Rank numbers and milliseconds are styled strictly in `JetBrains Mono` with right-aligned columnar alignment to guarantee jitter-free readability during active leader changes.

### Checkboxes, Radio & Toggles
- Custom rounded squares (6px radius for checkboxes) and circles for radios with 1.5px `#1F2430` borders. Checked states fill with `#8B5CF6` featuring a centered white vector icon and micro-flash illumination.

### Input Fields
- Dark input troughs with `#0F1219` background, 1px `#1F2430` perimeter, 12px radius, and `Plus Jakarta Sans` body copy. On focus, the border shifts to Sequence Recall violet (`#8B5CF6`) with a 4px soft outer spread.
